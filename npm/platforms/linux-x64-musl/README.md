# @ossido-labs/cli-linux-x64-musl

The Linux x64 (musl) prebuilt binary for the [ossido](https://ossido.dev) CLI.

This is a platform-specific dependency of [`@ossido-labs/ossido-cli`](https://www.npmjs.com/package/@ossido-labs/ossido-cli)
and is installed automatically on matching hosts. You do not need to install it directly.
