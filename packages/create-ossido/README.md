# create-ossido

Scaffold a new [ossido](https://ossido.dev) app.

```sh
npm create ossido@latest my-app
# or
bun create ossido my-app
```

This is a thin wrapper around `ossido new` (from
[`@ossido-labs/ossido-cli`](https://www.npmjs.com/package/@ossido-labs/ossido-cli)); all
arguments are forwarded, so the interactive wizard and flags (`--template`, `--tailwind`,
`--mdx`, `--yes`, …) work exactly as they do there.
